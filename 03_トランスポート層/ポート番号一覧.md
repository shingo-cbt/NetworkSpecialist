# ポート番号一覧（ネスペ出題観点）

出題度：◎ 午後のFWルール表・穴埋めで頻出／○ 午前で出る／△ 深追い不要

午後のFW（Firewall）のフィルタリングルール表を埋めるときに使う一覧。**★は特によく出るもの**。詳しくは各ノートを参照。

## 1. ポート番号の基本（○）

- **ポート番号**：TCP（Transmission Control Protocol）・UDP（User Datagram Protocol）で、**どのアプリケーションの通信か**を区別する番号（0〜65535）

| 範囲 | 名前 | 用途 |
|---|---|---|
| 0〜1023 | ウェルノウンポート | 代表的なサービス（サーバ側） |
| 1024〜49151 | 登録済みポート | 製品・サービスごとに登録された番号 |
| 49152〜65535 | 動的・プライベートポート | **クライアントの送信元ポート**として一時的に使う |

- FWのルールでは、**宛先ポート**（サーバ側の番号）を書くのが基本。クライアントの送信元ポートは毎回変わる

## 3. IPのプロトコル番号（◎：ポート番号を持たないもの）

- TCP・UDPの上ではなく、**IP（Internet Protocol）の上で直接運ばれる**プロトコル。FWでは「ポート番号」ではなく「**プロトコル番号**」で許可する

| プロトコル | 番号 | ポイント | ノート |
|---|---|---|---|
| ICMP（Internet Control Message Protocol） | 1 | ping、エラー通知 | [[ICMP]] |
| TCP | 6 | − | [[TCP]] |
| UDP | 17 | − | − |
| ★**GRE（Generic Routing Encapsulation）** | **47** | ポート番号がない → NAPT（Network Address Port Translation）を越えにくい | [[IPsec]] |
| ★**ESP（Encapsulating Security Payload）** | **50** | ポート番号がない → NAT-Tが必要 | [[IPsec]] |
| AH（Authentication Header） | 51 | NAT（Network Address Translation）と併用できない | [[IPsec]] |
| ICMPv6 | 58 | 丸ごと遮断しない | [[ICMP]] |
| ★**OSPF（Open Shortest Path First）** | **89** | − | [[OSPF]] |
| ★**VRRP（Virtual Router Redundancy Protocol）** | **112** | − | [[VRRP]] |

## 6. 覚え方

- **20番台は「ファイル転送とリモート操作」**：20・21 FTP、22 SSH、23 Telnet、25 SMTP
- **50〜60番台は「名前とアドレス」**：53 DNS、67・68 DHCP、69 TFTP
- **100番台は「受信と管理」**：110 POP3、123 NTP、143 IMAP、161・162 SNMP、179 BGP
- **暗号化版は「990番台」が多い**：990 FTPS、993 IMAPS、995 POP3S
- **VPN（Virtual Private Network）は「500と4500」**、RADIUSは「1812と1813」、SIPは「5060」
- **ポートがないのは「GRE 47、ESP 50」**

## 7. 使い方

> [!tip] 得点につながる覚え方
> 午後でFWのルール表が出たら、通信の要件を1行ずつ「送信元 → 宛先：プロトコル／ポート」に直し、この一覧で番号を確かめる。**UDPとTCPの両方が必要なもの（DNS、Kerberos、SIP）**、**ポート番号ではなくプロトコル番号で許可するもの（ESP、GRE）**、**向きで番号が変わるもの**（SNMPの161と162、DHCPの67と68）の3種類に注意する。
