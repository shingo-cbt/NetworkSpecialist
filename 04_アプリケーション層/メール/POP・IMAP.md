# POP・IMAP まとめ（ネスペ出題観点）

出題度：◎ 午後で記述・穴埋めとして頻出／○ 午前・午後小問で出る／△ 深追い不要

## 1. 基本（○）

- 受信者が、メールサーバの**メールボックスからメールを受け取る**プロトコル（送るのはSMTP（Simple Mail Transfer Protocol））

| | POP3（Post Office Protocol version 3） | IMAP（Internet Message Access Protocol） |
|---|---|---|
| ポート | **TCP（Transmission Control Protocol） 110**（POP3S（POP3 over SSL/TLS）：995） | **TCP 143**（IMAPS（IMAP over SSL/TLS）：993） |
| メールの置き場所 | **PCにダウンロード**する（通常はサーバから削除） | **サーバに置いたまま**操作する |
| 複数の端末 | 端末ごとにメールがばらばらになる | **どの端末からでも同じ状態**（既読、フォルダ）を見られる |
| サーバの容量 | 少なくて済む | 多く必要 |
| 通信 | 受信時にまとめてダウンロード | 開くたびにサーバへアクセスする |

- 暗号化：POP3S（995）、IMAPS（993）、またはSTARTTLSで途中からTLS（Transport Layer Security）に切り替える
- APOP（Authenticated POP）：パスワードをハッシュ値にして送るPOP3の認証。今は脆弱とされる（△）
- 午前の定番：「IMAPの特徴」→ サーバ上でメールを管理し、複数の端末から同じ状態で扱える

## 2. 午後で問われるテーマと記述の型

### ○ IMAPにする理由

- PCとスマートフォンなど**複数の端末でメールを使う**、**PCを紛失してもメールがサーバに残る**
- 記述の型：「メールをサーバ上で管理するため、複数の端末から同じ状態でメールを参照できるから」

### ○ パスワードの保護

- POP3・IMAPのままだと、**ID・パスワードが平文で流れる** → POP3S・IMAPS、STARTTLSで暗号化する
- クラウドのメールサービスでは、POP・IMAPを使わずWebメール・専用アプリ（多要素認証つき）にすることも多い

### ○ FWのルール

- 社内のPC → メールサーバ：TCP 993（IMAPS）または995（POP3S）
- → [[FW]]

## 3. 覚え方

- **POPは「郵便受けから持ち帰る」、IMAPは「郵便受けの中で読んで整理する」**
- **ポートは「POP 110／995、IMAP 143／993」**：暗号化すると900番台
- **複数の端末ならIMAP**

## 4. 勉強の優先順位

1. POP3とIMAPの違いと、IMAPを使う理由
2. ポート番号（110、143、995、993）
3. 平文のパスワードと暗号化
