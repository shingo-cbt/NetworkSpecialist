# NTP まとめ（ネスペ出題観点）

出題度：◎ 午後で記述・穴埋めとして頻出／○ 午前・午後小問で出る／△ 深追い不要

## 1. NTPの基本（○）

- **NTP（Network Time Protocol）**：ネットワーク上の機器の**時刻を正確に合わせる**プロトコル
- ポート：**UDP（User Datagram Protocol） 123**
- **階層構造（ストラタム）**

| ストラタム | 内容 |
|---|---|
| 0 | 原子時計、GPS（Global Positioning System）などの**基準となる時計** |
| 1 | ストラタム0に**直接つながった**NTPサーバ |
| 2 | ストラタム1から時刻を受け取るサーバ |
| … | 数字が大きいほど基準から遠い（最大15） |

- 通信の遅延を計算して補正するので、ネットワーク越しでも高い精度で合わせられる
- 社内では、**社内のNTPサーバが外部のNTPサーバ（ストラタムの小さいもの）と同期**し、社内の機器はその**社内NTPサーバと同期**する構成が一般的
- SNTP（Simple NTP）：NTPの簡易版。端末などで使う（△）

## 2. 時刻がずれると困ること（◎：午後の記述で最も問われる）

| 困ること | 理由 | 関連 |
|---|---|---|
| **ログの照合ができない** | 複数の機器のログを時系列で並べられず、障害・不正アクセスを調査できない | [[Syslog]] |
| **Kerberos認証に失敗する** | チケットに有効期限があり、時刻のずれが大きい（初期値5分）と認証できない。令和4年春 午後Ⅰ 問3で「PCとサーバの時刻同期」が解答になった | [[Kerberos]] |
| **証明書の検証に失敗する** | 証明書の有効期間の判定を誤る（まだ有効でない・期限切れと判断） | [[TLS]] |
| **ワンタイムパスワードが合わない** | 時刻を使って作るワンタイムパスワード（TOTP（Time-based One-Time Password））がずれる | − |
| SAML（Security Assertion Markup Language）のアサーションの有効期限 | 有効期間の判定を誤る | [[SAML]] |

- 記述の型（ログ）：「各機器の時刻がずれていると、複数の機器のログを時系列で照合できないから」
- 記述の型（Kerberos）：「チケットの有効期限を正しく判断できるよう、PCとサーバの時刻を同期させるため」

## 3. 午後で問われるテーマと記述の型

### ◎ 社内NTPサーバの構成

- 全機器が外部のNTPサーバに直接問い合わせると、**FW（Firewall）で多数の通信を許可**する必要があり、外部への依存も大きい
- **社内NTPサーバを1〜2台置き、それだけが外部と同期**する → FWの許可は社内NTPサーバだけで済む
- 社内NTPサーバを**冗長化**する（2台以上を参照させる）
- FWのルール：社内NTPサーバ → 外部のNTPサーバ：UDP 123 → [[FW]]

### ○ NTPを使ったリフレクション攻撃

- **攻撃者の観点**：古いNTPサーバの**monlistコマンド**（最近通信した相手の一覧を返す）は、小さな要求に**大きな応答**を返す → 送信元を詐称して送り、**増幅したDDoS（Distributed Denial of Service）攻撃の踏み台**にする（DNS（Domain Name System）リフレクタ攻撃と同じ仕組み）
- **防御側の対策**：monlistを無効にする（ソフトウェアを更新する）、**外部からのNTPの問い合わせに応答しない**、イングレスフィルタリング
- → [[DNSリフレクタ攻撃]]

### △ 偽の時刻

- 偽のNTPサーバから時刻を受け取ると、証明書の検証やログが狂う → 信頼できるNTPサーバだけを参照する、NTPの認証を使う

## 4. 覚え方

- **NTPは「みんなで時計を合わせる」**：UDP 123
- **ストラタムは「基準の時計からの距離」**：0が原子時計、1がそれに直結したサーバ
- **時刻がずれると困るのは「ログ・Kerberos・証明書・ワンタイムパスワード」**
- **社内は「代表のNTPサーバだけが外に聞きに行く」**
- **monlistは「小さく聞いて大きく返す」→ 踏み台になる**

## 5. 勉強の優先順位

1. 時刻がずれると困ること（ログ、Kerberos、証明書）を30〜40字で書けるようにする
2. 社内NTPサーバを置く構成と、FWのルール
3. ストラタムの意味
4. NTPのリフレクション攻撃と対策
5. SNTP、NTPの認証は名前を知っている程度でよい

> [!tip] 得点につながる覚え方
> NTPは単独の大問にはならないが、**認証（Kerberos）・ログ調査・証明書の問題の「解答」として**繰り返し出る。「〜できない原因」の設問で、時刻が関わる仕組み（有効期限、時系列）があれば、まずNTPを疑う。
