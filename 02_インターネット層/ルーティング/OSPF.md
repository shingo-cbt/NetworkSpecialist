# OSPF まとめ（ネスペ出題観点）

出題度：◎ 午後で記述・穴埋め・計算として頻出／○ 午前・午後小問で出る／△ 深追い不要

## 1. OSPFの基本（◎）

- **OSPF（Open Shortest Path First）**：**リンクステート型**のIGP（Interior Gateway Protocol）。企業ネットワークの標準
- 各ルータが**リンクの状態（LSA：Link State Advertisement）**を交換し、全ルータが同じ**LSDB（Link State Database：ネットワーク全体の地図）**を持つ
- 各ルータが自分を起点に **SPF（Shortest Path First）アルゴリズム（ダイクストラ法）**で最短経路を計算する
- **メトリックはコスト**（帯域から計算）。コストの合計が最小の経路を選ぶ
- 変化があったときだけLSAを送る → **収束が速い**、帯域の無駄が少ない
- **IP（Internet Protocol）のプロトコル番号89**で直接運ぶ（TCP（Transmission Control Protocol）・UDP（User Datagram Protocol）を使わない）
- 送信先：**224.0.0.5**（全OSPFルータ）、**224.0.0.6**（DR・BDR宛て）
- IPv6用は **OSPFv3**（IPv4用はOSPFv2）

## 2. コスト（◎）

- **コスト ＝ 基準帯域 ÷ インタフェースの帯域**（小数点以下は切り捨て、最小1）
  - 基準帯域の初期値は多くの機器で **100Mbps**
  - 100Mbps → 1、10Mbps → 10、1Mbps → 100
- ◎の定番：**1Gbpsも10Gbpsも、初期値のままだとコストは1** → 速さの違いが経路選択に反映されない
  - 対策：**基準帯域を大きくする**（例：100Gbps）、または**インタフェースのコストを手動で設定**する
  - 基準帯域は**全ルータで同じ値**にする
- **経路のコスト ＝ 宛先までに通る各ルータの「出ていくインタフェース」のコストの合計**
- **コストを調整して経路を制御する**：メインの回線のコストを小さく、バックアップの回線を大きくする → 平常時はメイン、障害時だけバックアップ
- コストが同じ経路が複数あれば **ECMP（Equal Cost Multi-Path）**で負荷分散
- 記述の型：「1Gbpsと10Gbpsのインタフェースのコストがどちらも1になり、帯域の差が経路選択に反映されないから」

## 3. 近隣関係とDR／BDR（○）

- **Helloパケット**で隣のルータを見つけ、近隣関係（ネイバー）を作る
  - 初期値：**Hello間隔10秒、デッド間隔40秒**（40秒Helloが届かなければダウンと判断）
- **近隣関係になるために一致が必要なもの**（午後で原因として問われる）
  - **エリアID**、**Hello間隔・デッド間隔**、**認証の設定**、**サブネット（ネットワークアドレスとマスク）**、（DBD交換時に）**MTU**（Maximum Transmission Unit）
  - 記述の型：「隣接するルータでHello間隔が一致していないため、ネイバー関係が確立しないから」
- **ルータID**：OSPFでルータを識別する32ビットの値。手動設定、なければループバックなどのIPアドレスの最大値
- **DR（Designated Router：代表ルータ）／BDR（Backup DR）**
  - Ethernetのように多数のルータがつながるネットワークでは、全員が互いにLSAを交換すると無駄が多い → **代表のDRとだけ交換**する
  - 選び方：**プライオリティが最大**のルータ → 同じなら**ルータIDが最大**のルータ。プライオリティ0はDRにならない
  - 後から優先度の高いルータを追加しても、**今のDRは交代しない**（△）
- 近隣の状態：Down → Init → **2-Way**（DR・BDR以外のルータ同士はここで止まる）→ ExStart → Exchange → Loading → **Full**（LSDBの同期完了）
- **パッシブインタフェース**：端末だけがつながるインタフェースではHelloを送らない（経路は広告する）→ 不要な近隣関係や、偽のルータとの接続を防ぐ

## 4. エリア（◎）

- 大きなネットワークを**エリア**に分け、LSAの詳細な交換を**エリア内に閉じ込める**
  - LSDBが小さくなる、SPF計算の負荷が減る、障害の影響が他エリアに広がらない
- **エリア0（バックボーンエリア）**：すべてのエリアは**エリア0に接続**しなければならない
- ルータの役割

| 役割 | 内容 |
|---|---|
| 内部ルータ | 1つのエリアだけに属する |
| **ABR（Area Border Router）** | **エリア0と他のエリアの境界**。エリア間で経路を伝え、**経路集約**できる |
| **ASBR（AS Boundary Router）** | **OSPF以外（BGP（Border Gateway Protocol）、スタティックなど）の経路を取り込む**ルータ |

- 主なLSA（○）

| タイプ | 名前 | 作る人 | 範囲 |
|---|---|---|---|
| 1 | ルータLSA | 全ルータ | エリア内 |
| 2 | ネットワークLSA | DR | エリア内 |
| 3 | サマリーLSA | ABR | 他エリアへ |
| 5 | AS（Autonomous System）外部LSA | ASBR | OSPF全体 |

- **スタブエリア**：外部経路（タイプ5）を受け取らず、デフォルトルートで代用する（△）
- 外部経路のメトリック：**E2（初期値）**は外部のコストだけ、**E1**は内部のコストも足す（△）

## 5. 午後で問われるテーマと記述の型

### ◎ コストの計算と経路の判定

- 各インタフェースのコストを求め、経路ごとに合計して最小を選ぶ
- 障害時に次に選ばれる経路、ECMPになるかを問う
- **コストを何以上にすれば、平常時にこの経路を使わないか**を計算させる問題も多い

### ◎ VRRPと組み合わせた冗長化

- L3スイッチを2台にして、端末のデフォルトゲートウェイはVRRP（Virtual Router Redundancy Protocol）、L3スイッチから先はOSPFで冗長化する
- **行きと帰りの経路を揃える**：VRRPのマスタ側のL3スイッチを通るように、OSPFのコストを調整する（揃っていないとFW（Firewall）のステートフルインスペクションで戻りが破棄される）
- 上流の回線が切れたら、VRRPの優先度を下げてマスタを交代させる（トラッキング）
- 令和7年春 午後Ⅰ 問1「企業ネットワークのルータ更改」でも、OSPFとVRRPの理解が問われている
- → [[VRRP]]

### ◎ 機器の更改・メンテナンス時の経路切替

- 停止させたいルータの**コストを大きくして通信を迂回させてから**止める → 通信を止めずに作業できる
- 記述の型：「当該ルータを経由する経路のコストを大きくし、通信を他方の経路に迂回させてから停止する」

### ○ ネイバー関係が確立しない原因

- エリアID、Hello間隔・デッド間隔、認証、サブネット、MTUの不一致（3章）

### ○ 他プロトコルとの連携

- スタティック経路やBGPで受けた経路を、ASBRでOSPFに**再配布**する
- デフォルトルートをOSPFで配る（インターネットへの出口のルータから）
- → [[再配布]]、[[BGP]]

### ○ 収束時間の短縮

- デッド間隔（40秒）を待たずに障害を検知するため、**BFD（Bidirectional Forwarding Detection）**を併用する

### △ セキュリティ

- 偽のルータが近隣関係を作り、**偽の経路を広告**して通信を引き寄せる → **OSPFの認証**、**パッシブインタフェース**で防ぐ

## 6. 覚え方

- **OSPFは「全員が同じ地図（LSDB）を持ち、各自がカーナビ（SPF）で最短経路を計算する」**
- **コストは「100M ÷ 帯域」**：1G以上はみんな1になる → 基準帯域を上げる
- **「ハロー10、デッド40」**：4回聞こえなければダウン
- **近隣の条件は「エリア・タイマ・認証・サブネット・MTU」**が合っていること
- **DRは「プライオリティ → ルータID、大きい方が勝つ」**
- **エリア0は「首都」**：全エリアは首都につながる。ABRは県境、ASBRは国境
- **プロトコル番号89、マルチキャスト224.0.0.5と6**

## 7. 勉強の優先順位

1. コストの計算と、経路の判定（障害時の切替、ECMP）を確実に解けるようにする
2. 1Gbps以上でコストが同じになる問題と対策を30〜40字で書けるようにする
3. VRRPとの組合せ（行きと帰りの経路を揃える、トラッキング）
4. コストを変えて通信を迂回させる、メンテナンスの手順
5. 近隣関係の成立条件、DR／BDRの選ばれ方
6. エリア、ABR／ASBR、LSAのタイプ
7. スタブエリア、E1／E2は名前を知っている程度でよい

> [!tip] 得点につながる覚え方
> OSPFは**午後の構成問題で最も出るルーティングプロトコル**。構成図を見たら、各リンクに**コストを書き込み**、宛先ごとに合計を計算してから設問を読む。「コストをいくつにすれば…」という問題は、平常時と障害時の両方の合計を比べて不等式を立てる。
