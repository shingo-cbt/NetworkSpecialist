# スタティックルーティング まとめ（ネスペ出題観点）

出題度：◎ 午後で記述・穴埋めとして頻出／○ 午前・午後小問で出る／△ 深追い不要

## 1. スタティックルーティングの基本（○）

- 管理者が**手動で経路（宛先ネットワークとネクストホップ）を設定**する方式
- 書き方の例：`宛先 192.168.10.0/24 → ネクストホップ 10.0.0.2`

| | スタティック | 動的（OSPF（Open Shortest Path First）、BGP（Border Gateway Protocol）など） |
|---|---|---|
| 設定 | 経路ごとに手動 | プロトコルの設定だけで経路は自動 |
| 障害時 | **自動では切り替わらない**（工夫が必要） | 自動で迂回する |
| ルータの負荷・帯域 | 小さい | 経路交換の分だけかかる |
| 向く場面 | 小規模、経路が1本、**インターネットへの出口（デフォルトルート）** | 冗長な経路がある中・大規模 |

- アドミニストレーティブディスタンスは**1**（直接接続の次に優先される）

## 2. デフォルトルート（◎）

- **0.0.0.0/0**：ルーティングテーブルのどの経路にも一致しないパケットの送り先
- ロンゲストマッチで最も短い（/0）ので、**ほかの経路がないときだけ**使われる
- 典型：拠点やインターネット接続のルータで「それ以外は全部ISP（Internet Service Provider）・上位のルータへ」
- OSPFで社内にデフォルトルートを配ることもある（出口のルータで設定）
- IPv6では **::/0**

## 3. フローティングスタティック（◎）

- スタティック経路の**アドミニストレーティブディスタンスを大きく**（動的な経路より大きく）設定し、**普段は使われないバックアップ**にする
  - 平常時：OSPF・BGPで学習した経路（値110・20など）が優先される
  - 障害で動的な経路が消える → フローティングスタティック（例：値200）が有効になる
- 2本のスタティック経路で、値を変えてメインとバックアップにする使い方もある
- 記述の型：「動的ルーティングの経路より大きいアドミニストレーティブディスタンスを設定し、障害時だけ有効になるバックアップ経路にする」

## 4. 午後で問われるテーマと記述の型

### ◎ ルーティングテーブルの空欄

- 構成図を見て、各ルータに必要なスタティック経路（宛先とネクストホップ）を埋める
- **行きの経路だけでなく、戻りの経路も必要**（片方向だけ設定して通信できないミスが問われる）
- 記述の型：「宛先からの戻りのパケットを転送するための経路が、ルータに設定されていないから」

### ◎ 障害時に切り替わらない問題

- スタティック経路は、**ネクストホップの先で障害が起きても経路が残り続ける**
  - 自分のインタフェースが**ダウン**すれば経路は消えるが、その先（スイッチの先、プロバイダ網の中）の障害は分からない
  - そのため、届かないネクストホップにパケットを送り続ける
- 対策
  - **経路監視（トラッキング）**：pingなどでネクストホップや宛先を定期的に確認し、届かなければその経路を無効にする
  - **BFD**（Bidirectional Forwarding Detection）と連動させる
  - 動的ルーティングに変える
- 記述の型：「スタティック経路はネクストホップより先の障害を検知できないため、経路が削除されず通信が途絶えるから」

### ○ 経路集約とNull0

- 拠点に割り当てたアドレスをまとめた経路を1本だけ設定する
- 集約経路の中で使っていない部分宛てのパケットがループしないよう、**Null0（破棄）への経路**を設定する（△）

### ○ 動的ルーティングとの組合せ

- スタティックで設定した経路（インターネット向けのデフォルトルートなど）を、**OSPFに再配布**して社内に広める
- → [[再配布]]

## 5. 覚え方

- **スタティックは「手書きの地図」**：書いたとおりにしか案内しない。道が壊れても書き換えない
- **デフォルトルートは「それ以外は全部あっち」**：0.0.0.0/0、最後の手段
- **フローティングは「普段は沈んでいて、主経路が消えると浮かび上がる」**：値を大きくして控えにする
- **経路は「行き」と「帰り」の両方**

## 6. 勉強の優先順位

1. 構成図からスタティック経路（宛先とネクストホップ）を埋められるようにする（戻りの経路も）
2. フローティングスタティックの仕組みを30〜40字で書けるようにする
3. ネクストホップの先の障害を検知できない問題と、トラッキング・BFDによる対策
4. デフォルトルートの役割
5. Null0は名前と目的を知っている程度でよい

> [!tip] 得点につながる覚え方
> スタティックは単純な分、午後では「**戻りの経路の設定漏れ」「障害時に切り替わらない」「フローティングで控えにする**」の3パターンで問われる。構成図の矢印を往復で追いかける。
