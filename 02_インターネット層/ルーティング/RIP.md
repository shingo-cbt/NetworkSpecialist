# RIP まとめ（ネスペ出題観点）

出題度：◎ 午後で記述・穴埋めとして頻出／○ 午前・午後小問で出る／△ 深追い不要

## 1. RIPの基本（○）

- **RIP（Routing Information Protocol）**：**ディスタンスベクタ型**のIGP（Interior Gateway Protocol）
- **メトリックはホップ数**（宛先までに経由するルータの数）
  - **最大15**。**16は到達不能（無限大）**を表す → 大規模なネットワークには使えない
- **30秒ごと**に、自分のルーティングテーブルを隣のルータに送る（定期更新）
- UDP（User Datagram Protocol）の**520番**を使う
- 現在の企業ネットワークでは、**OSPF（Open Shortest Path First）に置き換わっている**。午後では「RIPの欠点」「OSPFに移行する理由」として出ることが多い

## 2. RIPv1とRIPv2（○）

| | RIPv1 | RIPv2 |
|---|---|---|
| アドレスの扱い | **クラスフル**（サブネットマスクを送らない） | **クラスレス**（**サブネットマスクを送る**） |
| VLSM（Variable Length Subnet Mask：可変長サブネットマスク） | 使えない | **使える** |
| 送り方 | **ブロードキャスト** | **マルチキャスト（224.0.0.9）** |
| 認証 | なし | **あり** |

- IPv6用は **RIPng**（UDP 521）（△）
- 午前の定番：「RIPv2で追加された機能」→ サブネットマスクの通知、マルチキャスト、認証

## 3. RIPの問題点（◎）

| 問題 | 内容 |
|---|---|
| **ホップ数だけで選ぶ** | 回線の速さを考えない → **速い回線を3ホップ通るより、遅い回線を1ホップ通る経路**を選んでしまう |
| **最大15ホップ** | 大規模なネットワークに使えない |
| **収束が遅い** | 定期更新（30秒）を待って少しずつ伝わる。障害の検知にも最大180秒かかる |
| **ルーティングループ** | 障害時に、ルータ同士が互いに相手経由で届くと思い込み、ホップ数が少しずつ増え続ける（**無限カウント**） |
| **帯域の消費** | 変化がなくても30秒ごとにテーブル全体を送る |

- 記述の型（OSPFに移行する理由）：「RIPはホップ数で経路を選ぶため回線速度が考慮されず、収束にも時間がかかるから」
- 記述の型（遅い回線が選ばれる理由）：「RIPのメトリックはホップ数であり、回線の帯域を考慮しないから」

## 4. ループ対策（○）

| 対策 | 内容 |
|---|---|
| **スプリットホライズン** | ある経路を、**その経路を教えてくれたインタフェースには送り返さない** |
| **ポイズンリバース** | 教えてくれたインタフェースに、あえて**メトリック16（到達不能）**として送り返す |
| **トリガードアップデート** | 変化があったら30秒を待たず**すぐに**知らせる |
| **ホールドダウンタイマ** | 到達不能になった経路について、一定時間は他からの（古いかもしれない）情報を受け入れない |
| **最大ホップ数16** | 無限カウントになっても16で止まる |

- 午前で名前と内容の対応が問われる

## 5. 午後で問われるテーマと記述の型

### ○ 経路選択の判定

- 構成図で、RIPならホップ数、OSPFならコストで、どの経路が選ばれるかを比べさせる
- 「RIPでは遅い回線が選ばれ、OSPFでは速い回線が選ばれる」という対比が定番

### ○ OSPFへの移行

- 移行の理由：回線速度を考慮したい、収束を速くしたい、規模を大きくしたい
- 移行中はRIPとOSPFが混在するので、**再配布**が必要になる → [[再配布]]

### △ 小規模な拠点での利用

- 設定が簡単なので、古い機器や小規模なネットワークに残っている

## 6. 覚え方

- **RIPは「15まで数えられる、のんびり屋」**：16で無限、30秒ごとに話す、遅い
- **ホップ数は「乗り換え回数」**：特急（速い回線）でも乗り換えが多いと選ばれない
- **v2で「マスク・マルチ・認証」**の3つが増えた
- **スプリットホライズンは「教えてくれた人に、その話を返さない」**
- **UDP 520（RIPは「ご・に・ぜろ」）**

## 7. 勉強の優先順位

1. ホップ数で選ぶ問題点と、OSPFに移行する理由を30〜40字で書けるようにする
2. RIPv1とRIPv2の違い
3. ループ対策の名前と内容（午前）
4. 最大ホップ数、更新間隔、ポート番号

> [!tip] 得点につながる覚え方
> RIPは午後の主役になることは少なく、**OSPFとの比較（なぜOSPFを使うか）**として出る。「ホップ数」「収束が遅い」「15ホップまで」の3点を言えれば十分。
