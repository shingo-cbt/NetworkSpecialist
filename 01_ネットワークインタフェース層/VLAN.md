# VLAN まとめ（ネスペ出題観点）

出題度：◎ 午後で記述・穴埋めとして頻出／○ 午前・午後小問で出る／△ 深追い不要

## 1. VLANの基本（○）

### 前提：L2スイッチの基本動作（○）

- L2スイッチは、**MACアドレステーブル**（どのMAC（Media Access Control）アドレスの機器が、どのポートの先にいるか）を見てフレームを転送する
- **学習**：フレームを受け取ると、**送信元MACアドレスと受信したポート**をテーブルに記録する
- **転送**
  - 宛先MACアドレスがテーブルにある → **そのポートにだけ**送る
  - 宛先MACアドレスがテーブルにない、または**ブロードキャスト** → 受信したポート以外の**全ポートに送る（フラッディング）**
- **エージング**：一定時間（初期値300秒が多い）通信がないMACアドレスは、テーブルから消す
- この動きが、ほかのノートの前提になっている
  - VRRP（Virtual Router Redundancy Protocol）の切替やVM（Virtual Machine）の移動の後に**GARP（Gratuitous ARP）を送るのは、このテーブルを更新させるため** → [[Gratuitous ARP]]
  - **L2のループ**で同じ送信元MACが別々のポートから届くと、学習先がころころ変わる → [[STP]]
  - マルチキャストはそのままだとフラッディングされる → IGMP（Internet Group Management Protocol）スヌーピング → [[IPマルチキャスト]]
- **MACアドレステーブルを溢れさせる攻撃**（大量の偽のMACアドレスを送る）→ テーブルに入りきらないとフラッディングになり、通信を盗聴される → ポートごとに学習できるMACアドレスの数を制限する（ポートセキュリティ）（△）

### VLANとは

- 物理的な配線とは関係なく、**スイッチの中でL2のネットワーク（ブロードキャストドメイン）を論理的に分ける**技術
- 目的
  - **ブロードキャストの範囲を狭くする**（ARP（Address Resolution Protocol）などが全体に広がらない）
  - **部署・用途ごとにネットワークを分ける**（セキュリティ、管理）
  - 席替え・組織変更のときに、配線を変えずに設定だけで所属を変える
- **異なるVLAN（Virtual LAN）同士は、L3（ルータ、L3スイッチ）を経由しないと通信できない**
- 種類

| 種類 | 所属の決め方 | ポイント |
|---|---|---|
| **ポートVLAN**（スタティック） | スイッチの**ポートごと**に設定 | 最も基本 |
| **タグVLAN**（IEEE802.1Q） | フレームに付けた**VLANタグ**で区別 | 1本の線で複数VLANを運ぶ（トランク） |
| **ダイナミックVLAN** | **認証結果**やMACアドレスで決める | 802.1XのRADIUS（Remote Authentication Dial In User Service）がVLAN番号を指定 |

## 2. IEEE802.1Qタグ（◎）

- 送信元MACアドレスの後ろに**4バイトのタグ**を挿入する

| 項目 | ビット数 | 内容 |
|---|---|---|
| TPID（Tag Protocol Identifier） | 16 | **0x8100**（タグ付きフレームであることを示す） |
| **PCP（Priority Code Point、CoS：Class of Service）** | **3** | **優先度（0〜7）** → QoS（Quality of Service）で使う |
| DEI（Drop Eligible Indicator） | 1 | 廃棄してよいか（△） |
| **VID**（VLAN Identifier） | **12** | **VLAN番号**。使えるのは1〜4094 |

- タグの分だけフレームが大きくなる（最大1518 → **1522バイト**）
- VLAN番号は12ビットなので**最大約4,000個** → これが足りないデータセンターではVXLAN（Virtual eXtensible LAN）を使う（△）

## 3. アクセスポートとトランクポート（◎）

| | アクセスポート | トランクポート |
|---|---|---|
| 所属するVLAN | **1つ** | **複数** |
| タグ | 付けない（端末はタグを知らない） | **タグを付けて**送る |
| つなぐ相手 | PC、プリンタなどの端末 | スイッチ同士、スイッチとルータ、**AP（Access Point）やサーバ（複数VLANを扱う機器）** |

- **ネイティブVLAN**：トランクポートで**タグを付けずに**送るVLAN
  - 両端でネイティブVLANの設定が違うと、別のVLANにフレームが紛れ込む（△）
- **トランクで許可するVLAN**を絞る：必要なVLANだけ通すと、不要なブロードキャストが流れない
- 午後の定番：「スイッチのポート設定表の空欄（アクセス／トランク、VLAN番号）」を埋める

## 4. VLAN間ルーティング（◎）

- VLANが違えば、IP（Internet Protocol）のサブネットも別にする（**1VLAN＝1サブネット**が基本）
- 方法
  - **L3スイッチ**：VLANごとに**仮想的なインタフェース（SVI（Switched Virtual Interface）、VLANインタフェース）**を作り、そこにIPアドレスを設定してルーティングする → 高速、現在の主流
  - **ルータ＋トランク**（ワンアーム）：ルータの1つの物理ポートに、VLANごとの**サブインタフェース**を作る → ルータとの間の1本の線が混みやすい
- 各VLANの端末の**デフォルトゲートウェイ＝そのVLANのSVI（またはサブインタフェース）のIPアドレス**
- 問われ方：「端末に設定するデフォルトゲートウェイのアドレス」「VLAN間で通信できない原因」

## 5. 午後で問われるテーマと記述の型

### ◎ VLANの設計と設定表

- 部署、用途（業務、サーバ、管理用、ゲスト、IP電話）ごとにVLANを分ける
- どのスイッチのどのポートを、どのVLAN・アクセス／トランクにするかを表で問われる
- 記述の型（分ける理由）：「ブロードキャストの範囲を限定し、部署間の通信をL3スイッチで制御できるようにするため」
- **VLANを追加したときの設定漏れ**（午後の定番）
  - L2スイッチ：端末のポートをそのVLANのアクセスポートにする、**上位へのトランクポートの許可VLANに追加**する
  - L3スイッチ：**そのVLANのSVIを作成し、デフォルトゲートウェイのアドレスを設定**する（直接接続のネットワーク同士は自動でルーティングされるので、経路の設定は不要）
  - 記述の型：「L3スイッチとのトランクポートで、追加したVLANの通過を許可していないから」

### ◎ 無線LANとVLAN

- **SSID（Service Set Identifier）ごとにVLANを対応付ける**（社員用SSID → 業務VLAN、ゲスト用SSID → ゲストVLAN）
- APは複数のVLANを扱うので、**APとスイッチの間はトランク**にする
- ゲストVLANは、インターネットへの経路だけ許可し、社内への通信をL3スイッチやFW（Firewall）で遮断する
- → [[WPA]]、[[IEEE802.11]]

### ◎ ダイナミックVLAN（802.1Xとの組合せ）

- RADIUSサーバが、認証結果と一緒に**VLAN番号を通知**し、スイッチ・APがその端末をそのVLANに入れる
- 同じポート・同じSSIDでも、利用者の所属ごとに接続先を変えられる（フリーアドレスの職場）
- → [[IEEE802.1X]]、[[LDAP]]

### ○ スパニングツリーとVLAN

- VLANごとにスパニングツリーを動かす方式（PVST（Per-VLAN Spanning Tree）など）では、**VLANごとにルートブリッジを変えて**、冗長な経路を両方使う（負荷分散）
- → [[STP]]

### ○ VRRPとVLAN

- L3スイッチを2台にし、**VLANごとにVRRPのマスタを分ける** → 平常時に両方のL3スイッチを使う（負荷分散）
- → [[VRRP]]

### ○ QoS（CoS）

- 802.1Qタグの**PCP（3ビット）**でフレームの優先度を示す（IP電話を優先するなど）
- **タグがない区間（アクセスポート、ルータの先）ではCoSは消える** → L3ではDSCP（Differentiated Services Code Point）を使う
- → [[QoS]]

### △ その他

- **VXLAN**：L2のフレームを**UDP（User Datagram Protocol）に入れて**L3ネットワークを越えて運ぶ。識別子（VNI：VXLAN Network Identifier）は24ビットで約1,600万個。データセンター、クラウドで使う
- **Q-in-Q**：タグを二重に付ける。通信事業者の広域イーサネットで、利用者のVLANをそのまま運ぶ
- **プライベートVLAN**：同じVLAN内でも、端末同士の通信を禁止する

## 6. 覚え方

- **VLANは「1つの建物（スイッチ）の中に、壁で区切った部屋を作る」**：部屋をまたぐには廊下（L3）を通る
- **タグは「4バイト、VIDは12ビット（約4,000）、優先度は3ビット」**
- **アクセスは「端末に1本」、トランクは「スイッチ同士で束ねて運ぶ」**
- **「1VLAN＝1サブネット、デフォルトゲートウェイはそのVLANのSVI」**
- **SSIDとVLANはセット**：APとスイッチの間はトランク

## 7. 勉強の優先順位

1. アクセスポートとトランクポートの使い分けを、構成図の設定表で埋められるようにする
2. VLAN間ルーティング（L3スイッチのSVI）と、端末のデフォルトゲートウェイ
3. 802.1Qタグの構造（VID 12ビット、PCP 3ビット、4バイト）
4. 無線LAN（Local Area Network）のSSIDとVLANの対応付け、ゲストVLANの分離
5. ダイナミックVLAN、STP（Spanning Tree Protocol）・VRRPとの組合せによる負荷分散
6. VXLAN、Q-in-Q、プライベートVLANは名前と目的を知っている程度でよい

> [!tip] 得点につながる覚え方
> VLANは単独の大問より、**ほぼすべての構成問題の「土台」**として出る。構成図を見たら、まず**VLANとサブネットの対応表**を自分で書き、どこがトランクか、デフォルトゲートウェイはどこかを確認してから設問を読む。
