# STP まとめ（ネスペ出題観点）

出題度：◎ 午後で記述・穴埋めとして頻出／○ 午前・午後小問で出る／△ 深追い不要

## 1. STPの基本（◎）

- **STP（Spanning Tree Protocol：スパニングツリープロトコル）**：L2スイッチを冗長化した**ループのあるネットワークで、一部のポートを止めてループをなくす**プロトコル（IEEE802.1D）
- L2でループがあると
  - **ブロードキャストストーム**：ブロードキャストが無限に回り続け、帯域とスイッチの処理を使い果たす（L2のフレームにはTTL（Time To Live）がない）
  - **MACアドレステーブルの不安定**：同じMAC（Media Access Control）アドレスが複数のポートから届き、学習先が頻繁に変わる
- STPは、普段は冗長な経路を**ブロッキング**（止める）し、障害時にそのポートを**フォワーディング**（使う）に切り替える
- スイッチ同士は **BPDU**（Bridge Protocol Data Unit）を交換して状態を決める

## 2. ツリーの作り方（◎）

### ① ルートブリッジを決める

- **ブリッジID（ブリッジプライオリティ＋MACアドレス）が最小**のスイッチがルートブリッジになる
  - ブリッジプライオリティの初期値は **32768**（4096単位で設定）
  - 全部初期値なら、**MACアドレスが最小**のスイッチ → 意図しない古いスイッチがルートになることがある
  - **ルートブリッジにしたいスイッチのプライオリティを小さく設定**する
- **ルートブリッジのポートはすべて指定ポート**（フォワーディング）

### ② 各スイッチのルートポートを決める

- **ルートポート**：ルートブリッジへの**パスコストの合計が最小**のポート（ルートブリッジ以外の各スイッチに1つ）
- パスコストの例（IEEE802.1D-1998の値）：10Mbps＝100、100Mbps＝19、1Gbps＝4、10Gbps＝2
- 同じなら、相手のブリッジIDが小さい方 → 相手のポートIDが小さい方

### ③ 各リンクの指定ポートを決める

- **指定ポート**：リンクごとに、**ルートブリッジに近い側**（コストが小さい側）のポート
- **ルートポートにも指定ポートにもならなかったポートがブロッキング**（非指定ポート）

- 問われ方：「どのポートがブロッキングになるか」「ルートブリッジが故障したらどこが次のルートになるか」

## 3. ポートの状態と収束時間（○）

| 状態 | 内容 |
|---|---|
| ブロッキング | BPDUの受信だけ。フレームは転送しない |
| リスニング | BPDUを送受信してポートの役割を決める（15秒） |
| ラーニング | MACアドレスを学習する（15秒） |
| フォワーディング | フレームを転送する |

- 障害を検知してから切り替わるまで **30〜50秒**かかる（最大エージタイム20秒＋15秒＋15秒）
- その間は通信できない → 収束が遅いことがSTPの最大の欠点

## 4. RSTPとMSTP（○）

| | STP（802.1D） | **RSTP（Rapid STP、802.1w）** | **MSTP（Multiple STP、802.1s）** |
|---|---|---|---|
| 収束 | 30〜50秒 | **数秒以下** | RSTPと同じく速い |
| ツリーの数 | 1つ | 1つ | **複数（インスタンス）** |
| 特徴 | − | 代替ポート（ルートポートの予備）を用意し、すぐに切り替える | **VLAN（Virtual LAN）のグループごとに別のツリー**を作り、ブロックするポートを変えて**負荷分散**できる |

- **PVST（Per-VLAN Spanning Tree）**：Cisco社独自の、VLANごとにツリーを作る方式（△）
- **エッジポート（PortFast）**：端末をつなぐポートは、リスニング・ラーニングを飛ばして**すぐにフォワーディング**にする
  - 端末の起動時に30秒待たされて、**DHCP（Dynamic Host Configuration Protocol）でアドレスを取れない**問題を防ぐ
- **BPDUガード**：エッジポートでBPDUを受信したら、そのポートを止める → 利用者が勝手にスイッチをつないでループを作るのを防ぐ

## 5. 午後で問われるテーマと記述の型

### ◎ ルートブリッジの位置とVRRPのマスタを揃える

- ルートブリッジは**コアスイッチ**（L3スイッチ）にする。末端のスイッチがルートになると、通信が遠回りする
- **VRRP（Virtual Router Redundancy Protocol）のマスタと同じL3スイッチをルートブリッジ**にする → ブロッキングがマスタへの経路上に来ない
- MSTPやPVSTで、**VLANごとにルートブリッジを変え、VRRPのマスタも同じように分ける** → 平常時に両方のL3スイッチと両方の経路を使う
- 記述の型：「ルートブリッジとVRRPのマスタを同一のL3スイッチにすることで、ブロッキングポートを経由しない最短の経路で通信させるため」
- **予備のルートブリッジも決めておく**：L3SW1を最小（例：4096）、L3SW2を2番目（例：8192）にする → L3SW1の故障時に、MACアドレス任せで末端のL2スイッチがルートになることを防ぎ、意図どおりL3SW2がルートになる
- → [[VRRP]]、[[VLAN]]

### ◎ ブロッキングポートの判定

- 構成図にブリッジプライオリティ、MACアドレス、リンク速度が書かれていて、ルートブリッジ → ルートポート → 指定ポート → ブロッキングの順に決めさせる
- 障害時（リンク断、ルートブリッジ故障）の新しいツリーも同じ手順で求める

### ◎ 収束時間の短縮・STPを使わない構成

- 収束に30〜50秒かかる → **RSTPに変更**する
- **スタック構成＋リンクアグリゲーション**にすれば、論理的にループがなくなり**STPでポートを止めずに両方のリンクを使える**
- 記述の型：「スタックとリンクアグリゲーションを用いると、論理的にループのない構成となり、すべてのリンクを使用できるから」
- → [[リンクアグリゲーション]]

### ○ ループの発生と対策

- STPを無効にしていた、利用者がハブで2本つないだ → ブロードキャストストーム
- 対策：**BPDUガード**、**ストームコントロール**（ブロードキャストの量を制限）、ループ検知機能

## 6. 覚え方

- **STPは「ループする道路に通行止めを置く」**：普段は止め、事故（障害）のときだけ開ける
- **ルートブリッジは「ブリッジIDが一番小さい人」**：プライオリティ32768 → 同じならMACアドレス。小さくしたスイッチが勝つ
- **ルートポートは「ルートへの近道（各スイッチに1つ）」、指定ポートは「各リンクのルート側の代表」、残りが通行止め**
- **STPは「30〜50秒」、RSTPは「数秒」**
- **エッジポートは「端末用の即開通」**、BPDUガードは「スイッチがつながったら閉める」
- **ルートブリッジとVRRPのマスタは同じ機器に**

### プライオリティの向き：STP・VRRP・OSPFの比較

- **STPのプライオリティは「ID（番号）」の一部**：ブリッジID（プライオリティ＋MACアドレス）の先頭部分
  - STPは、ルートブリッジのID → ルートまでのコスト → 自分のブリッジID → ポートIDの順に比べ、**すべて「小さい方が優れている」**という1つのルールで判定する。向きがそろっているので、1回の比較で決められる
  - イメージは「番号の若い方が先輩」。同点ならMACアドレスが小さい方。これも同じ向き
- これに対し、[[VRRP]]の優先度と[[OSPF]]のDR（Designated Router）プライオリティは「**点数（やる気）**」なので、大きいほど強い（0は不参加）

| 種類 | 例 | 向き | 同点のとき |
|---|---|---|---|
| **番号・距離** | STPのブリッジID、STP・OSPF（Open Shortest Path First）のコスト | **小さいほど優先** | MACアドレスが小さい方（STP） |
| **点数（やる気）** | VRRPの優先度、OSPFのDRプライオリティ | **大きいほど優先**（0は不参加） | IP（Internet Protocol）アドレスが大きい方（VRRP）、ルータIDが大きい方（OSPF） |

- 覚え方：**「STPは背番号、VRRPとOSPFのDRは点数、コストは距離」**
- 設計者がこの向きを選んだ経緯の記録はない。上は仕組みから説明できる理由で、覚えるための整理

## 7. 勉強の優先順位

1. ルートブリッジ → ルートポート → 指定ポート → ブロッキングの判定を、構成図で解けるようにする
2. ルートブリッジとVRRPのマスタを揃える理由を30〜40字で書けるようにする
3. RSTP・MSTPの特徴（収束の速さ、VLANごとのツリーによる負荷分散）
4. スタック＋リンクアグリゲーションでSTPを使わない理由
5. エッジポート、BPDUガード、ストームコントロール
6. ポートの状態の名前、パスコストの値は午前で確認する程度でよい

> [!tip] 得点につながる覚え方
> STPは**L2の冗長化とVRRPの組合せ**で出る。構成図を見たら、まず**どのスイッチがルートブリッジか**、次に**どのポートがブロッキングか**に印を付け、VRRPのマスタと同じ機器か、障害時にどこが開くかを確認する。
